# Toggling bits

A bitwise **XOR** *flips* every bit that is set in the mask: a 1 in the mask
inverts the corresponding bit of the value, a 0 leaves it alone. The immediate
instruction is **`xori`**.

For example, XOR-ing `n` with `0x80` (decimal 128, bit 7) produces:

```asm
xori  r3, r3, 128
blr
```

XOR is the bit-twiddler's toggle switch: applying the same mask twice returns
the original value. Like `ori`, `xori` carries no dot and leaves the condition
register alone.

The target below uses a different mask constant. Read the decimal immediate,
find which bit(s) are toggled, and write the C expression.

```asm
xori  r3, r3, 64
blr
```

## Your task

Write `func_8012acac` to match the target.

<!-- solution -->

u32 func_8012acac(u32 x) {
    return x ^ 0x40;
