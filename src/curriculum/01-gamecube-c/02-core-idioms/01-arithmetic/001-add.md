# Reading a three-operand instruction

Three operands. That's the shape of every PowerPC arithmetic instruction. Take
`add rD, rA, rB`, which means `rD = rA + rB`. The part that trips everyone up
is the order: destination first, the two sources after it. Mix that up once and
you won't do it twice.

Two `int` arguments? The ABI lines them up left to right in `r3` and `r4`. So
look at the target for a moment. What expression over those two registers would
the compiler boil down to a single `add`?

## Your task

Write `func_802c37f8` to reproduce the target assembly.

<!-- solution -->
```c
int func_802c37f8(int a, int b) {
    return a + b;
}
```
