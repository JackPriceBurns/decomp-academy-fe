# Multiply low

PowerPC multiplies two registers with one instruction, **`mullw rD, rA, rB`**
("multiply low word"). It keeps the low 32 bits of the product and throws away
the rest:

```asm
mullw r3, r3, r4
blr
```

There's no immediate version of `mullw`. Multiply by a *variable* and you get
`mullw`; multiply by a constant and you get `mulli`, which you saw in the
warm-up. (One special kind of constant — a power of two — skips even `mulli`.
That's the next lesson.)

## Your task

Write `func_8037dd24` so it compiles to the `mullw` above.

<!-- solution -->
```c
int func_8037dd24(int a, int b) {
    return a * b;
}
```
